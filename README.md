
# FlexTech - Week 3 JavaScript Project

## Project Overview
FlexTech is a responsive website enhanced with JavaScript to provide an interactive user experience.

## Objectives
- Learn DOM manipulation.
- Use JavaScript event listeners.
- Add interactive features to a static webpage.
- Improve user experience across mobile and desktop devices.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
1. Responsive website layout.
2. Interactive navigation menu.
3. Dark mode toggle.
4. Welcome message button.
5. Dynamic content update.
6. Contact form validation.
7. Mobile-friendly design.

## Project Files
- `index.html` - Website structure.
- `style.css` - Styling and responsive layout.
- `script.js` - Interactive JavaScript functionality.

## How to Run
1. Download or clone this repository.
2. Keep all three files in the same folder.
3. Open `index.html` in a web browser.

## Testing
The buttons, theme toggle, navigation, and form validation should be tested on mobile and desktop screens.

## Learning Outcome
This project demonstrates basic JavaScript programming, DOM manipulation, event handling, and responsive web design.
